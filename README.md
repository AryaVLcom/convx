# convx.aryavl.com

Official song sharing portal, resolver, and artwork display for **Convx Music**.

## Features

- **Liquid Glass Aesthetics:** Handcrafted physical layering, SVG displacement lens bending, and ambient refraction.
- **Dynamic Track Resolution:** Resolves shared YouTube / Innertube songs, playlists, and channels on the fly via client-side oEmbed.
- **Deep Android App Linking:** Seamlessly launches `intent://convx.aryavl.com/watch?v=...` into the Convx Android player (`com.convx.music`).
- **Open Graph & Social Previews:** High-resolution preview cards for WhatsApp, Discord, Telegram, and Twitter.
- **App Links Verification:** Serves `/.well-known/assetlinks.json` for Android App Links domain verification.

## Deployment

Hosted on **GitHub Pages** with custom domain `convx.aryavl.com`.

### DNS Configuration

To point your custom domain `convx.aryavl.com` to this GitHub Pages site:
- **Type:** `CNAME`
- **Name:** `convx`
- **Target:** `aryavlcom.github.io`
